## Recent updates worth watching

- **Copilot code review API:** You can now request a Copilot code review through the REST and GraphQL APIs and set the effort level per request. Balanced is now the default effort level. Source: [GitHub Changelog, Oct 2, 2026](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level).
- **Copilot computer use (public preview):** Copilot CLI and the GitHub Copilot app on macOS and Windows can interact with desktop apps after you approve it. Turn it on with `/computer on`. Source: [GitHub Changelog, Oct 1, 2026](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps).
- **macOS 14 runner retirement:** The GitHub Actions macOS 14 runner image retires on November 2, 2026, with scheduled brownouts in October. Switch workflows to `macos-latest` or `macos-15`. Source: [GitHub Changelog, Oct 1, 2026](https://github.blog/changelog/2026-10-01-github-actions-macos-14-runner-image-retirement).
